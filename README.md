# Las Marikarmen — web

Static website for Las Marikarmen, in the style of the 2026 press kit.
Short info on the home page, one page per topic:

| Page | File | Also contains |
|---|---|---|
| Inicio | `/` | |
| Quiénes somos | `/quienes-somos/` | Miembros (`#members`), Prensa (`#prensa`) |
| Espectáculo | `/espectaculo/` | Talleres (`#talleres`), Conciertos (`#conciertos`) |
| Música | `/musica/` | Blob (`#blob`), Letras (`#letras`) |
| Blob Marikarmen | `/blob/` | |
| Tienda | `/tienda/` | |
| Contacto | `/contacto/` | |

Addresses have no `.html` (each page is `<slug>/index.html`; other languages under `/<lang>/<slug>/`). Anchors go after the slash: `/musica/#blob`.

The sections live in `templates/_prensa.html`, `_talleres.html`, `_conciertos.html`, `_letras.html`.
The old addresses (`blob.html`, `musica.html`… and `letras.html`, `talleres.html`, `conciertos.html`, `prensa.html`, also without `.html`) forward to the new spot,
so links already shared keep working. Menu: `NAV` in `build.py`.

Social icons, contact and press kit appear once, in the footer of every page.
Bottom left: pink triangle ▼ opens the accessibility options. Bottom right: ▲ back to top.
Hidden toy on every page except `/blob/` (`assets/js/fluid.js`): long-press ~0.4 s → a fireball brews under the finger; flick → it's thrown and dissolves;
keep holding 3 s more → full-screen fluid game, which dissolves back after 2 s without touching (or Esc). Off with reduced motion (⏸️) and in `#edit`. Timings at the top of the file.

**Gigs:** admin → *Fechas y carteles* (or `content/gigs.json`; posters in `assets/img/posters/`). Past dates move by themselves to "Lo petamos…", grouped by year (the site rebuilds every night).
**Lyrics:** edit lyrics in `letras/songs.json`, translations in `letras/out/*.json` (one array per language: es en ca gl eu pt fr it de ja; each language page shows only its own), descriptions and credits in `letras/build.py` (texts starting with `@` are `lyr_*` keys in `content/i18n/<lang>.json`).
**Shop:** admin → *Tienda: productos* (`content/merch.json`); remove a product when it sells out.

## Where things live

**Editing without code:** see `UPDATING.md` — forms at **/admin/**, or any page + **#edit**. Every change is a commit; the workflow translates, builds and publishes in 3–5 minutes.

- **`content/i18n/<lang>.json`** — every text on the site, one file per language (`es` is the reference), grouped by page section. Keys match the press-kit master text where they exist.
- **`content/*.json`** — one file per admin form: `gigs`, `videos`, `merch`, `music`, `press`, `venues`, `members`, `credits`, `contact`, `downloads` (PDF per language), `theme` (colours).
- **`content/site.json`** — technical settings, no form (languages, addresses). **`content/facts.json`** — names, pronouns, fixed terms (translator + checker).
- **`admin/`** — the forms admin (Sveltia CMS); `admin/web/config.yml` is generated by `tools/make_config.py`.
- **`templates/`** — page layouts (Jinja2).
- **`assets/`** — CSS, photos, logos, icons, press-kit PDFs.

Names are never translated and never broken across lines: Hipogrifa (ella), Victoria Sickness (elle), Contàmina Perpétua (elle).
Pronouns: ES elle · CA elli · DE dey/dem.

## Publish on GitHub Pages (once)

1. Create a new repository on github.com (e.g. `lasmarikarmen-web`) and upload these files (or `git push`).
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Every push to `main` rebuilds and publishes the site. The address appears under Settings → Pages (first `https://<user>.github.io/lasmarikarmen-web/`).
4. When ready to move the domain: write `lasmarikarmen.com` in `cname` in `content/site.json`, add the domain in Settings → Pages → Custom domain, and point the DNS to GitHub Pages at your domain provider.

You can also edit the `content/` files directly on github.com (pencil icon) — the site rebuilds by itself.

## Link previews

WhatsApp, Telegram and Signal show a picture and title when a page link is shared. The pictures are in
`assets/img/og/` (one per page, 1200×630). To remake them after changing photos: `node tools/make_og.js`.
Apps cache previews for a while, so a changed picture may take days to show on links already shared.

## Languages

Published: es (root), en, ca, gl, eu, pt, fr, it, de, ja — each in its own folder (`/en/`, `/ca/`…).
The language button sits in the top bar, next to the menu. On a first visit, the home page opens in the
browser's language if the site has it; after that the visitor's choice is remembered.

- Edit any text in the admin (*Textos*, all languages side by side) or in `content/i18n/<lang>.json`.
- Check what is missing: `python3 build.py --check`
- Texts changed in one language are translated into the others after each push (`tools/translate.py`, Softcatalà; not Japanese). Always read the result.
- To give one language to a translator: send `content/i18n/<lang>.json` (or let them use the admin).
- To hide a language, remove it from `languages` in `content/site.json`.

## Build locally

```
pip install -r requirements.txt
python3 build.py
python3 -m http.server -d _site 8000   # open http://localhost:8000
```
